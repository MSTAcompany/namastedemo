# Шаблон сайта студии йоги/пилатеса

Переиспользуемый статический сайт (HTML/CSS/JS). Вся кастомизация под клиента —
в **одном файле** `js/config.js`. Кастомизация под нового клиента: **20–40 минут**.

## Как посмотреть

Просто открой `index.html` в браузере (двойной клик). Всё работает без сборки и
интернета (кроме шрифта Google Fonts — при желании можно заменить на системный).

## Как кастомизировать под клиента (по шагам)

Открой `js/config.js` и поменяй под клиента:

1. **`brand`** — название студии и 2 цвета (`primary`, `accent`). Меняешь два цвета —
   меняется вся палитра сайта.
2. **`meta`** — заголовок вкладки и описание (для поиска).
3. **`hero`** — главный экран: заголовок-УТП, подзаголовок, текст кнопки. Фон:
   положи фото в `assets/` и укажи путь в `bgImage` (пусто = фирменный градиент).
4. **`features`** — 3 преимущества.
5. **`schedule`** — расписание по дням (время, занятие, тренер).
6. **`trainers`** — тренеры (имя, направление, био, фото). Без фото — покажутся
   инициалы на градиенте.
7. **`memberships`** — абонементы и цены. `highlighted: true` — выделить тариф.
8. **`reviews`** — отзывы. Поле `mapsWidgetHtml` — задел под будущий виджет отзывов
   с Яндекс.Карт / 2ГИС (вставишь код виджета позже).
9. **`contacts`** — адрес, телефон, почта, часы, соцсети. Карта: вставь код iframe
   из Яндекс.Конструктора карт в `mapEmbedHtml` (пусто = кнопка «Открыть на карте»).
10. **`booking`** — куда уходит заявка (см. ниже).

Фото клиента складывай в папку `assets/` и ссылайся на них из `config.js`.

## Форма записи — 3 варианта (по сложности)

Настраивается в `config.booking`:

- **Проще всего (без бэкенда):** оставь `endpoint: ""` и укажи `fallbackWhatsapp`
  (номер без `+`, напр. `79000000000`) или `fallbackTelegram` (ник без `@`). При
  отправке формы откроется WhatsApp/Telegram с уже заполненным текстом заявки.
- **Правильно (уведомление админу в Telegram):** разверни serverless-функцию
  `serverless/telegram-notify.js` на Netlify или Vercel и впиши её URL в
  `booking.endpoint`. Бот-токен хранится на сервере, на сайте не светится.
- **Если у клиента есть YCLIENTS/CRM:** можно вести кнопку записи прямо на их
  виджет (заменить форму ссылкой) — сделаем под конкретный случай.

### Подключение Telegram-уведомлений (кратко)

1. Создай бота у **@BotFather** → получишь `BOT_TOKEN`.
2. Напиши своему боту любое сообщение, затем открой
   `https://api.telegram.org/bot<BOT_TOKEN>/getUpdates` и возьми `chat.id`.
3. На Netlify/Vercel задай переменные окружения `TELEGRAM_BOT_TOKEN` и
   `TELEGRAM_CHAT_ID`, залей функцию из `serverless/`.
4. В `config.js` укажи `booking.endpoint` = URL функции.

## Как опубликовать (бесплатно)

- **Netlify / Vercel:** перетащи папку в дашборд (drag-and-drop) — получишь ссылку.
- **GitHub Pages:** залей папку в репозиторий, включи Pages.
- Либо отдать файлы клиенту на его хостинг.

## Структура

```
site-template/
  index.html            # каркас (менять не нужно)
  css/styles.css        # стили (менять не нужно)
  js/config.js          # ← ВСЯ кастомизация здесь
  js/main.js            # рендер-логика (менять не нужно)
  assets/               # фото клиента
  serverless/telegram-notify.js  # функция уведомлений в Telegram
```
